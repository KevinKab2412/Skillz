---
name: trash
kind: concept
purpose: Undo a deletion.
familiar_as: the Trash / Recycle Bin on a desktop
misconception: Its purpose is deleting, and deleting frees space. Space comes back only when the trash is emptied.
op: delete x → restore x → x is accessible again; delete x → empty → x is gone for good
state: accessible items · trashed items
actions: create · delete · restore · empty
syncs: with folder (the trash is a folder; restoring = moving out)
visual: One table with a 'where' column; delete flips the row, empty strikes it out. Trap beat: usage after delete.
sources: Daniel Jackson, The Essence of Software (2021), ch. 4, ch. 6
origin: seed · jackson
tags: [concept]
---
