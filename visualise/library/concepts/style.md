---
name: style
kind: concept
purpose: Keep formatting consistent across many elements.
familiar_as: a CSS class
misconception: Applying a style copies its format once (TextEdit's near miss); changing the style later wouldn't update anything.
op: give e1 and e2 style s → redefine s → both e1 and e2 change
state: assigned (element → style) · defined (style → format)
actions: assign · define
syncs: with format (overrides), with theme (style sheets)
visual: Two elements wired to one style card; redefine the card and both repaint together.
sources: Daniel Jackson, The Essence of Software (2021), ch. 4, ch. 11
origin: seed · jackson
tags: [concept]
---
