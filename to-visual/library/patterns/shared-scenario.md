---
name: shared-scenario
kind: pattern
purpose: Keep every figure on a page consistent, and let one change update them all.
when: Pages with several figures about the same system.
how: One set of example values (the scenario) that every block reads; editing a value updates every figure (Litt's Notion EV page; Embark's views over one outline).
sources: Geoffrey Litt — explain-diff (https://gist.github.com/geoffreylitt/a29df1b5f9865506e8952488eac3d524), 'Understanding is the new bottleneck' (2026), 'Dynamic Documents as Personal Software' (Recurse Center)
origin: seed · litt
