---
name: commit
kind: concept
purpose: Record coherent snapshots of a project you can return to.
familiar_as: a git commit
misconception: Commits are backups (the denied purpose: committing half-done work pollutes history).
op: commit at a coherent point → later compare or revert to it
state: commit graph (commit → parent, snapshot)
actions: commit · revert · branch · merge
syncs: with backup (keep them separate)
visual: A chain of snapshot cards; revert walks back along the chain.
sources: Daniel Jackson, The Essence of Software (2021), ch. 9
origin: seed · jackson
tags: [concept]
---
